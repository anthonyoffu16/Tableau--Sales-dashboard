# Tableau--Sales-dashboard
Interactive Tableau dashboard analysing sales by product sub-category and geographic distribution

📌 Project Overview

This project presents an interactive Tableau dashboard analysing sales performance across product sub-categories and geographic regions.

The dashboard allows users to explore sales trends and understand how different product segments perform across states.

📂 Datasets Used

1) Orders dataset
2) People dataset
3) Returns dataset

Relationships were established between these datasets to enable integrated analysis.

⚙️ Key Features

1) Top 10 Product Sub-Categories
   
Bar chart showing highest-performing sub-categories by sales

2) Geographic Sales Distribution

Map visualising sales volume across different states

3) Interactive Dashboard

i) Selecting a sub-category dynamically updates the map

ii) Enables focused regional analysis


🛠 Tools Used

1) Tableau
2) Data visualisation techniques
3) Interactive dashboard design

🚀 Insights

 -Identified top-performing product categories
 
 -Observed regional sales concentration 
 
 -Enabled drill-down analysis through interactivity
